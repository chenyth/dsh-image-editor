# 开发路线

## 0. 项目初始化

- [x] 独立 GitHub 开源仓库与 MIT 许可。
- [x] DSH 原生插件清单、ESM 入口与只读开发状态工具。
- [x] 中英文名称、介绍与透明红色火焰图标。
- [x] 自动检查、打包与真实宿主合同测试。

## 1. 验证编辑器承载

- [ ] 验证目标 DSH 版本的 UI 扩展或本地页面承载方式。
- [ ] 验证 CanvasKit、Worker、字体、WebGL 与软件渲染。
- [ ] 明确共享编辑器提取方式与第三方许可。
- [ ] 用一张本地图片完成打开、显示和关闭，卸载后释放资源。

## 2. 手工编辑与导出

- [ ] 接入当前工作区的图片读取与文档保存。
- [ ] 接入文字、图片和图形图层、撤销与重做、位图工具。
- [ ] 保留原图与重建图的画布、用户图层和资产边界。
- [ ] 验证 PNG/JPG 导出，再验证 PSD 图层与字体效果。
- [ ] 验证文件不覆盖、文档重开、修订冲突与异常恢复。

## 3. 云端能力与 AI 图层分离

- [ ] 明确服务端对外 API、OAuth 权限和私有资产传输合同。
- [ ] 接入个人账号授权、云端文档和历史项目恢复。
- [ ] 接入分离报价、用户确认、异步任务与部分失败处理。
- [ ] 验证原任务重试、取消、账务回执与授权恢复。

## 4. 发行与市场收录

- [ ] macOS DSH 桌面验收；Windows 单独验收。
- [ ] 发布真实操作截图、已测范围与限制。
- [ ] 固定版本 tarball、哈希和正式 GitHub Release。
- [ ] 达到可用标准后提交 awesome-dsh-plugin 市场 PR。

本次只完成初始化。后续里程碑分别开发与验收；初始化版本不作为可用编辑器提交市场。
