# 图层编辑集成架构

记录日期：2026-10-31。本文区分已验证的初始化合同与待实现的集成方案。

## 当前实现

采用 ESM 与 Cordis 原生插件结构，通过 `dsh.bundle.patch` 加载。仅注入 `tools` 服务，注册只读的 `shenhuo_image_editor_info`。DSH 从已导出的 `locale/en.json` 与 `locale/zh.json` 读取显示名称和介绍。

宿主合同基线是 DSH `0.2.1-rc.5`。工具具有显式输入和输出 JSON Schema；元数据读取与工具生命周期由该版本真实宿主模块验证。宿主模块测试不代表 Electron 安装或画布实测。

官方格式参考：[Tools](https://github.com/deepseek-ai/deepseek-harness/blob/master/docs/subsystems/tools.md)、[Boot](https://github.com/deepseek-ai/deepseek-harness/blob/master/docs/subsystems/boot.md)。正式发布前重新核对目标版本。

## 计划的模块边界

| 边界 | 职责 | 当前状态 |
| --- | --- | --- |
| DSH 插件 | 注册工具，关联会话与本地工作区，管理编辑器生命周期 | 仅状态工具 |
| 编辑器界面 | 图层列表、画布、文字/图片/图形编辑、撤销与重做 | 待验证 DSH UI 承载方式 |
| 宿主适配 | 请求、上传、资产和字体读取、下载与保存 | 待实现 |
| 文档与导出 | 保留规范化像素坐标、独立图层、版本和导出语义 | 待实现 |
| 神火服务适配 | 个人授权、云端文档、分离报价、任务与作品领取 | 待确认对外合同 |

优先沿用神火现有编辑器的宿主注入边界；界面承载需验证 DSH 的扩展接口、资源加载、WebGL/软件渲染和 CanvasKit Worker，再决定使用宿主面板还是受控本地编辑器页面。本阶段不承诺任一方案已经可用。

初始化仓库没有复制神火服务端、内部模型配置、提示词、字体包或完整编辑器源码。提取共享前端模块时再明确版本、构建、许可与上游修订，避免维护两份失去关联的编辑器实现。

## 必须保留的编辑合同

- `shenhuo.layer/v1` 是文档协议版本，与已停用的旧设计师工作流 V1 无关。规范化后的原图像素是坐标基准，运行时 SceneGraph 是派生表示。
- 原始资产、永久根源图、当前工作源和派生背景分别保留；原图与重建图的独立用户图层不互相烘焙。
- 受保护背景、AI 文字组和用户图层组保留各自职责；分离成功后原子替换 AI 子树，失败不破坏稳定画布。
- 文本、图片和图形保存与位图草稿应用保持独立。自动保存采用修订冲突检测，写操作重试使用稳定幂等键。
- 导出使用实际选中画布的图层归属。PNG/JPG 合成、PSD 图层及字体保真度须单独验证；`.pen` 为派生格式，不承诺外部 `.pen` 往返。

## 授权、文件与计费

现有站内图层 API 与设计师远程 MCP 是不同边界。后续接入个人 OAuth 前需要核对图层资源权限、私有资产传输、云端 API 与服务端授权范围，不能复用站内 Cookie 或假定设计师 MCP 已包含图层 API。状态工具不读取 `dsh-image-designer` 的令牌文件。

本地文件操作应限制在当前用户选定工作区内，验证实际路径、图片格式与尺寸；保存不得静默覆盖源图。账号凭证保留在受限宿主侧，不写入模型参数或页面地址。

付费 AI 图层分离需真实报价与明确确认，任务终态轮询、部分失败、取消、幂等重试和费用展示以服务回执为准。初始化阶段没有云端请求或付费行为。
