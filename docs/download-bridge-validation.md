# 下载桥接验证结论

2026-11-02：在 macOS DSH Desktop `0.2.1-rc.5` 中验证通过。

```text
WebView 内生成测试 PNG
  → 服务签发单文件短期票据
  → DSH onOpenRequested 交接到插件外壳
  → 用户点击保存
  → 插件 Host 下载、校验、保存
```

已得到真实的 600 × 360 PNG 文件，30,752 字节，网页和本地 SHA-256 一致。重复使用同一票据被拒绝，没有重复落盘。交接过程中未把网页登录 Cookie 传给插件，也没有关闭 DSH 的 WebView 下载限制。

这是本地测试页、测试签票服务和独立验收插件完成的机制验证；线上编辑器尚未接入。原型、运行方法、验证证据和上线前缺口见 [下载桥接验收原型](../experiments/download-bridge/README.md)。生成包、临时凭据、文件与截图只留在本机 `artifacts/`，不进入公开源码或正式安装包。

建议继续沿用线上编辑器，增加导出交接入口与服务端文件票据。正式插件应复用 DSH 支持的 Host 通信和保存能力，并分别验收真实账号归属、保存位置、取消、失败恢复、大文件与 PSD；不用提取或重写编辑器。
