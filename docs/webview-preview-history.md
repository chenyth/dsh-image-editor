## 自动验证

Node.js `25.9.0`；CI 使用 Node.js 24。`npm run check`、`npm run build`、10 项测试及安装包构建通过。测试包括实际发布的 DSH 元数据解析与工具生命周期、客户端 bundle 注册合同、URL 检查、guest 释放、取消竞态、网络错误与工作区分区。

实际宿主模块通过 `DSH_HOST_MODULE_DIR` 加载 `@deepseek-ai/dsh@0.2.1-rc.5`，不是自行模拟该两项宿主测试。浏览器生命周期测试使用受控 guest 替身；它们不能单独证明 Electron 交互可用，以上桌面操作提供另行证据。截图与个人文档标识保存在本机，不进入公开仓库。

## 已知边界

WebView 的工作区会话由 DSH 管理；宿主退出后不保存 Cookie，不能承诺免登录恢复。MCP OAuth 与网页登录独立。插件只持久化去除 query/fragment 的编辑器地址，不保存用户凭证或素材。源码与本地包已准备，不等于正式发布或市场收录。
